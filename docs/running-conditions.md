# 运行条件

## 作品集状态

本仓库是供招聘方查看的核心代码和方案快照，不是完整 MediaCrawler 分发包，也不包含真实平台运行数据。

## 完整本地系统曾使用的环境

- Windows 10/11；
- Python 3.11；
- `uv` 或可安装 `pyproject.toml` 依赖的Python环境；
- Node.js 与 npm；
- Chrome；
- Playwright；
- 本地 FastAPI WebUI；
- SQLite；
- 用户本人完成小红书或抖音登录。

## 第三方无法直接运行的原因

- 本作品集没有复制完整开源底座；
- 没有包含平台登录状态；
- 没有包含数据库和历史评论注册表；
- 触达后端仍是本机MVP，尚未完成跨电脑打包；
- 平台页面和验证机制可能变化；
- 真实平台操作需要账号持有人自行确认。

## 如果后续制作可运行演示版

建议只提供离线 Demo：

1. 使用 `demo-data/sample_leads.csv`；
2. 模拟搜索、判断、去重和审核状态；
3. 不连接真实平台；
4. 不执行发布或私信；
5. 将真实平台适配器作为需要用户自行配置的可选模块。

这能让招聘方验证产品流程，同时避免把账号、平台变化和合规风险混入演示。
