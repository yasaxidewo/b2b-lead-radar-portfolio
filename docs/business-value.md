# 从工具产出到业务结果

## 服务的销售环节

```text
目标客户与场景假设
→ 公开需求信号发现
→ 线索优先级判断
→ 人工触达
→ 需求确认
→ Demo / 方案 / 报价
→ 商机与结果复盘
```

本项目目前主要覆盖前四步。它能帮助验证“哪些行业、竞品和问题更容易产生有效沟通”，但不能替代需求访谈、产品演示、报价和商机推进。

## 应验证的业务问题

1. 哪类搜索词带来的有效线索率更高？
2. 哪类痛点更容易得到用户回复？
3. 哪些回复能继续进入需求确认？
4. 高监管行业是否更关注合规、安全和权限？
5. 竞品抱怨是否真的意味着更换意愿？
6. 什么时候应该停止继续扩大抓取，而改为人工访谈？

## 推荐漏斗指标

| 环节 | 指标 |
|---|---|
| 搜索 | 每个关键词返回内容数、相关内容率 |
| 评论 | 实际评论数、业务相关评论率 |
| 线索 | 审核通过数、可定位率、重复率 |
| 触达 | 发送数、有效回复数、负面反馈数 |
| 需求 | 需求确认数、关键问题和采购触发事件 |
| 推进 | Demo、方案、报价、试点和商机数 |
