# Lead Radar source snapshots

这里保留四个能够代表本次业务化改造的代码快照：

- `industry_profiles.py`：行业、业务场景和约束需求配置；
- `douyin_profiles.py`：抖音平台搜索词和选帖参数；
- `leadRadarQueries.ts`：搜索词预览与启动请求共用的纯函数；
- `LeadRadarConfigPanel.tsx`：搜索来源、竞品和行业的两阶段选择界面。

这些文件来自本地 `v3.5.2 / 7260959` 快照。它们依赖完整 MediaCrawler 项目的类型、API和运行环境，因此不作为独立可运行包发布。
