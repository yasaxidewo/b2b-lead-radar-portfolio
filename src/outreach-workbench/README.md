# Outreach Workbench source snapshots

这里保留人工审核触达工作台的前端和 Chrome 扩展快照，用于展示任务审核、字段校验、状态追踪和单条评论辅助交互。

## 内容

- `dm-agent/public`：用户级私信审核台前端；
- `batch-agent/public`：评论批次审核台前端；
- `comment-copilot`：需要用户最终确认发布的 Chrome 扩展。

## 为什么没有提交运行后端和浏览器资料

本地 MVP 的运行后端仍依赖特定目录、Codex 内置 Node 运行时和平台登录环境。作品集阶段不把它包装成第三方可直接运行的产品，也不提交专用 Chrome 用户目录、账号登录状态或执行记录。

## 执行边界

- 所有话术必须人工审核；
- 定位时交叉核对评论 ID、昵称和评论原文；
- 验证码、频率限制、账号告警或浏览器断开时停止；
- 不调用裸私信接口，不导出 Cookie，不绕过平台控制。
